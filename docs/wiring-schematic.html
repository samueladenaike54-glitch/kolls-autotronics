⚡ Kolls Autotronics — Complete Wiring Schematic

ESP32 + SN65HVD230 CAN + 1.8" TFT + LM2596 Power + OBD-II

📋 Pin-by-Pin Wiring Table

FROM WIRE TO NOTES
🔴 POWER CIRCUIT
OBD-II Pin 16 RED wire 5A Fuse IN +12V (car) or +24V (truck)
5A Fuse OUT RED wire LM2596 VIN+ Fuse protects everything downstream
LM2596 VOUT+ GREEN wire ESP32 3V3 pin ⚠️ Adjust LM2596 potentiometer to 3.3V BEFORE connecting!
LM2596 VOUT+ GREEN wire SN65HVD230 VCC 3.3V power to CAN transceiver
LM2596 VOUT+ GREEN wire TFT VCC pin 3.3V power to TFT display
⚫ GROUND (COMMON BUS)
OBD-II Pin 4/5 BLACK wire LM2596 VIN− Vehicle chassis ground
LM2596 VOUT− BLACK wire ESP32 GND Shared ground bus
ESP32 GND BLACK wire SN65HVD230 GND Common ground
ESP32 GND BLACK wire TFT GND pin Common ground
🟡 CAN BUS (Vehicle Data)
OBD-II Pin 6 YELLOW wire SN65HVD230 CANH CAN High differential signal
OBD-II Pin 14 BLUE wire SN65HVD230 CANL CAN Low differential signal
SN65HVD230 TX GREEN wire ESP32 GPIO 5 CAN transmit (ESP32 TWAI TX)
SN65HVD230 RX GREEN wire ESP32 GPIO 4 CAN receive (ESP32 TWAI RX)
🟣 TFT DISPLAY (SPI Bus)
ESP32 GPIO 15 PURPLE wire TFT CS Chip Select
ESP32 GPIO 16 PURPLE wire TFT RST Reset
ESP32 GPIO 2 PURPLE wire TFT DC (A0) Data/Command select
ESP32 GPIO 23 PURPLE wire TFT SDA (MOSI) SPI data out
ESP32 GPIO 18 PURPLE wire TFT SCK (CLK) SPI clock
TFT LED/BLK — 3.3V (via 100Ω) Backlight (always on). Some modules have no resistor needed.
💡 STATUS LED
ESP32 GPIO 25 wire 220Ω Resistor → LED Anode (+) Green=CAN OK, Blue=Sync, Red=Fault
LED Cathode (−) BLACK GND Common ground
🔋 BATTERY BACKUP
18650 Battery + RED ESP32 VIN (via Schottky diode) Diode prevents backfeed from LM2596
18650 Battery − BLACK GND bus Common ground

⚠️ CRITICAL: Before Powering On

  1. Adjust LM2596 FIRST: Connect 12V to LM2596 input. Turn the potentiometer screw with a screwdriver while measuring output with a multimeter. Set to exactly 3.3V before connecting anything else.
  2. Double-check GND: ALL components must share the same ground bus. A floating ground will cause random crashes or CAN read failures.
  3. CAN wiring: CANH (yellow) and CANL (blue) must NOT be swapped. Verify OBD-II Pin 6 = CANH, Pin 14 = CANL.
  4. No 5V to ESP32 GPIO: The SN65HVD230 must run on 3.3V. If you use a 5V version, you'll fry the ESP32 GPIO pins.
  5. Battery diode: Place a Schottky diode (e.g. 1N5819) on the 18650 positive wire with the stripe facing the ESP32 — this prevents the main power from charging the battery.
