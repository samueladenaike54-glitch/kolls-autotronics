# Orion X sticker

Print files for the Orion X device sticker.

## Files

- `orion-x-sticker.svg` — vector artwork, 60 × 60 mm, rounded sticker with a die-cut edge.
- `orion-x-sticker.png` — 2400 × 2400 px square render, suitable for home printing or a print shop. At 60 mm this is about 1016 dpi.
- `orion-x-sticker-a4.svg` — A4 sheet with 12 square 60 × 60 mm stickers and dashed cut guides.
- `orion-x-sticker-a4.pdf` — print-ready A4 PDF of the 12-up sheet. This is the easiest file to print.
- `preview.html` / `preview-a4.html` — browser previews only. Do not print these.

## Printing

1. Print at **100%** / **Actual size**. Do not use “Fit to page” or “Scale to fit”.
2. For the A4 sheet, cut along the dashed guides. The sheet uses square stickers so there are no white corner gaps.
3. For the rounded sticker, use the SVG and ask for a **die-cut** around the outer rounded edge, or print the PNG and cut a square.
4. Matte or satin vinyl with a laminate finish looks best on a device. Gloss also works but shows fingerprints.
5. The design uses `#151614` charcoal, `#3ddb9a` brand green, and `#f7f7f2` off-white.

## Font note

The wordmark uses Arial Black. The PNG already contains the rendered artwork, so use the PNG if your print app substitutes fonts or changes the spacing.
